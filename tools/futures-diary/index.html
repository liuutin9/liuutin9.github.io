開帳前

接上你的帳本

貼上你部署 Apps Script 後拿到的 /exec 網址，資料會直接讀寫你自己的 Google Sheet。這組網址只存在這台裝置的瀏覽器裡。

網址看起來不太對，請確認是完整的 /exec 網址。

還沒有自己的帳本？四步驟設定好

  1. 1
    複製 Google 試算表模板

    打開這份範本，左上角「檔案 → 建立副本」，存成一份完全屬於你自己的試算表。複製完成後，到 Init 分頁設定「每日目標報酬率」（預設 10%）。

  2. 2
    部署成你自己的網頁應用程式

    在複製出來的試算表裡開啟「擴充功能 → Apps Script」，Code.gs 會自動帶著原本的程式碼，不用改動，直接部署即可。點右上角「部署 → 新增部署作業」，類型選 網頁應用程式，執行身分選 我，誰可以存取選 所有人，按部署。

    第一次部署會跳出「Google 尚未驗證這個應用程式」的警告畫面，這是正常的——因為這是你自己部署給自己用的程式，不是別人做的。點畫面上的「進階」，再點「前往（不安全）」繼續就可以了。

  3. 3
    貼上你的網址

    部署完成會拿到一組 .../exec 網址，把它貼到最上面的輸入框，按「連接帳本」——之後這個網址都會存在你這台裝置的瀏覽器裡，不用每次重貼。

  4. 4
    加到手機桌面，開起來就像 App

    iPhone 用 Safari 打開這個網址，點下方工具列的分享圖示，往下滑找「加入主畫面」。Android 用 Chrome 打開，點右上角選單（⋮），選「加入主畫面」或「安裝應用程式」。

    加進去之後桌面會多一個圖示，點開會全螢幕顯示、不會看到網址列，用起來跟一般 App 幾乎沒有差別。
